# novaprom-marketing

Локальный плагин Claude Code с маркетинговыми скиллами для НОВАПРОМ — российского производителя
нефтегазового оборудования (камеры СОД КПР-НП, затворы ЗК-НП, фильтры ФГ-НП/ФЖ-НП, сепараторы СГ-НП/НГС,
блочно-модульное оборудование, резервуары, КТП). Промышленный B2B: Яндекс в первую очередь, читатели —
инженеры, проектировщики и снабжение, длинный цикл сделки с опросными листами, ТКП и тендерами.

Версия 1.0.0. Только Markdown: без скриптов, хуков и MCP-серверов. Источники, коммиты, лицензии и
локальные патчи — в [NOTICE.md](NOTICE.md).

## Как подключить

Плагин будет внесён в маркетплейс репозитория `.claude-plugin/marketplace.json` (его создаёт основной
агент). После этого:

1. Добавьте маркетплейс репозитория: `/plugin marketplace add <путь к клону Claude-code>`.
2. Установите плагин: `/plugin install novaprom-marketing@<имя маркетплейса из marketplace.json>`
   (или включите его в `enabledPlugins` настроек Claude Code).
3. Перезапустите Claude Code и проверьте, что в списке скиллов есть `novaprom-marketing:*`.

Описания 16 скиллов — около 12 тыс. символов (≈3 тыс. токенов) в каждой сессии. Если это заметно,
включайте плагин только в рабочей папке маркетинга (настройки проекта), а не глобально.

## Как начать работу

1. Работайте из одной рабочей папки маркетинга: контекст-файл ищется относительно неё
   (`.agents/product-marketing.md`).
2. Запустите `product-marketing` в режиме «с нуля» по документам компании и сайту novaprom.ru (режим
   «из кодовой базы» здесь не подходит). Скилл добавит в файл раздел «Рынок, каналы и ограничения» из
   `skills/product-marketing/references/ru-b2b-industrial-overlay.md`.
3. Дальше любые маркетинговые скиллы и субагенты читают этот файл первыми. Для JTBD — `jtbd-industrial`,
   он предложит обновить разделы *Jobs to be done*, *Switching Dynamics*, *Customer Language*.

## Границы применения

- **Инженерия и цены — не маркетинг.** Скиллы и субагенты плагина никогда не рассчитывают и не проверяют
  технические параметры, типоразмеры, материалы, давления, массы, цены, себестоимость и сроки. Технические
  значения в текстах — только из утверждённых паспортов и каталогов. Расчёты — скиллы `novaprom-*`
  (gas-filtration, gas-hydraulics, gas-reduction, pressure-vessels, heat-exchangers, piping,
  valves-closures, pig-launchers, materials); стоимость — `novaprom-cost-estimation`; КП/ТКП —
  `novaprom-commercial-proposal`; выпуск расчётов и ТКП заказчику — через `novaprom-engineering-review`.
- **Опросный лист и ТКП.** Маркетинг отвечает за форму, CTA, шаблон для скачивания, структуру и
  формулировки; заполнение, оценка параметров и все цифры — инженерия.
- **Сайт и публикации.** Никаких изменений на живом сайте, в CMS MODX, соцсетях, рассылках, CRM и рекламных
  кабинетах без явного согласия пользователя. Изменения сайта — через скилл `novaprom-website`.
- **Право.** Утверждения о 152-ФЗ, 156-ФЗ, 38-ФЗ и 135-ФЗ в overlay помечены «требует подтверждения
  юристом». Страницы с названиями конкурентов, сравнения и превосходные степени — только после юридической
  проверки.
- **Сторонний код.** Скиллы не запускают npm/npx и внешние CLI; инструменты из upstream `tools/` не
  устанавливать. Подключение платных MCP (DataForSEO, Firecrawl и т.п.) — только с согласия пользователя.
