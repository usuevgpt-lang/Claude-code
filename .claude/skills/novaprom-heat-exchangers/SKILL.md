# Теплообменное оборудование (НОВАПРОМ)

## Правила
1. Это предварительный тепловой расчёт для ТКП и компоновки. Окончательный — специализированное ПО
   (HTRI, Aspen EDR, отечественные аналоги) или методика изготовителя; механика — ГОСТ 34233.7-2017.
2. U, коэффициенты теплоотдачи, сопротивления загрязнений, константы пучка (K1, n1) — с источником
   (справочник, ПО, данные аналога). «Типовые диапазоны U» допустимы только для порядка величины с пометкой.
3. Свойства газа — `novaprom-gas-hydraulics` (CoolProp по составу при наличии); воды/гликоля — справочник с источником.
4. Проверка реализуемости обязательна: пересечение температур, F ≥ 0,75 (практика), скорости в трубах
   (загрязнение / эрозия / ΔP), отношение длины к диаметру, транспортные габариты, температурные
   напряжения (нужен ли компенсатор/плавающая головка/U-трубы), доступ для чистки.
5. Формат: ИСХОДНЫЕ ДАННЫЕ → ИСТОЧНИК → ФОРМУЛА → ПОДСТАНОВКА → РЕЗУЛЬТАТ → ПРОВЕРКА.

## Расчёты (`scripts/hx_calc.py`)
`heat_balance` · `lmtd` (counter / parallel / 1-2n) · `overall_u` · `area` · `tubes` · `bundle`.

```bash
python ${CLAUDE_SKILL_DIR}/scripts/hx_calc.py input.json --out report.md
```

## Типовая цепочка «подогрев газа перед редуцированием»
1. `novaprom-gas-hydraulics` → `jt_cooling`: температура после редуцирования без подогрева.
2. Требуемая температура после редуцирования (ОЛ/ОТТ, гидраты, материалы) → требуемая t газа перед редуцированием.
3. `novaprom-gas-hydraulics` → `preheat`: тепловая мощность.
4. `hx_calc.py`: баланс по теплоносителю, LMTD, U (по аналогу или расчёту), площадь, пучок.
5. Компоновка, прочность (`novaprom-pressure-vessels`), стоимость (`novaprom-cost-estimation`).

Справочные константы пучка (K1, n1) — `references/bundle-constants.md` (статус «сверить с источником»).
