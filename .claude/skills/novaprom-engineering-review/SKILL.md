# Многоагентная инженерная проверка (НОВАПРОМ)

## Когда обязательна
- расчёт уходит заказчику, в экспертизу, в КД или в ТКП с гарантированными параметрами;
- задача затрагивает ≥ 2 дисциплины (например, газодинамика + прочность + стоимость);
- результат отличается от аналога/прототипа более чем на 15 % или от ожиданий пользователя;
- в исходных данных есть «ИСТОЧНИК НЕ УКАЗАН» или справочные значения со статусом «не сверено».

## Схема
```
MAIN AGENT (оркестратор)
  1. Фиксирует постановку: исходные данные + источники, применимые нормативы, критерии приёмки
  2. ENGINEERING AGENTS (параллельно, каждый в своей дисциплине):
       pressure-vessel-engineer / gas-process-engineer / filtration-specialist / heat-exchanger-specialist ...
       → расчёт скриптом навыка, отчёт в формате ИСХОДНЫЕ ДАННЫЕ → … → ПРОВЕРКА
  3. INDEPENDENT CALCULATION: engineering-reviewer получает ТОЛЬКО постановку (не результаты!)
       → пересчитывает другим путём: вручную по формулам стандарта / альтернативный метод /
         другая программа; для Z — другой метод; для площадей — другая декомпозиция
  4. REVIEWER: сравнивает результаты, проверяет исходные данные, нормативы, единицы, применимость
  5. CONTRADICTION CHECK: таблица расхождений (см. ниже), каждое — причина и решение
  6. FINAL RESULT: MAIN сводит итог; открытые вопросы и допущения выносятся отдельно; пользователь утверждает
```

## Правила независимости
- Проверяющий не видит чисел первого расчёта до завершения своего (передавать только постановку).
- Метод проверки должен отличаться хотя бы одним: формула/источник, порядок вычислений, инструмент.
- Совпадение «до последней цифры» при разных методах подозрительно — проверить, не скопированы ли данные.

## Критерии расхождения (по умолчанию; пользователь может изменить)
| Величина | Допустимое расхождение |
|---|---|
| Толщины, допускаемые давления (одинаковая методика) | ≤ 0,5 % (округление) |
| Z, плотность газа (разные методы) | ≤ 2 % |
| Скорости, расходы | ≤ 1 % |
| Тепловые расчёты (разные методы U) | ≤ 15 % — с объяснением |
| Стоимость | диапазон, а не точка; расхождение объясняется источниками цен |

## Таблица противоречий (формат вывода)
| № | Что сравнивается | Расчёт A | Расчёт B | Расхождение | Причина | Решение | Кто подтверждает |
|---|---|---|---|---|---|---|---|

Типовые причины: разная база расхода (ст./норм.), абсолютное/избыточное давление, прибавки, φ, [σ] при другой
температуре, наружный/внутренний диаметр, единицы (кгс/см² vs МПа vs бар), устаревшая редакция норматива.

## Итоговое заключение
1. Вывод: «соответствует / не соответствует / требует уточнения исходных данных».
2. Что проверено и чем (методы, документы).
3. Расхождения и как закрыты.
4. Допущения и открытые вопросы.
5. Кто должен утвердить (ответственный инженер) — Claude не подписывает документы.
