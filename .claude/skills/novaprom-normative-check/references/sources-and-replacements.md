# Источники статуса документов и типовые замены

## Где проверять (в порядке надёжности)
| Источник | Что даёт | Примечание |
|---|---|---|
| Росстандарт: каталог/фонд стандартов (rst.gov.ru и связанные ФГИС) | официальный статус, даты введения/отмены | первичный источник |
| ЕЭК (eec.eaeunion.org) | тексты ТР ТС/ЕАЭС, перечни стандартов к ТР | первичный источник для ТР |
| publication.pravo.gov.ru | официальные публикации приказов (ФНП Ростехнадзора и др.) | первичный для НПА |
| docs.cntd.ru (Кодекс/Техэксперт) | статус и часто текст, связи «заменён на» | вторичный; сверять с первичным при сомнении |
| Сайты заказчиков (transneft.ru, gazprom.ru и др.) | перечни ОТТ/СТО, если опубликованы | многие документы выдаются только по запросу |

В отчёте указывать: источник статуса + дата проверки.
