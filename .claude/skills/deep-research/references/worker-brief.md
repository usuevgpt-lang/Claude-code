# Бриф для research-worker

```
ID задачи: T<n>
Цель: <что выяснить>
Решение, которое поддерживаем: <зачем>
Запросы (начать с коротких и широких): RU: «…», «…»; EN: "…", "…"
Приоритетные уровни источников: T1, T2 (см. source-policy)
Искать опровержения: <какие данные могли бы опровергнуть ожидаемый вывод>
Нельзя упоминать в запросах: <конфиденциальное>
Правило остановки: <когда достаточно>
Бюджет: ≤ <N> обращений к инструментам

- Замеченные противоречия: …
- Пробелы и наводки для следующей волны: …
- Выполненные запросы: …
```
