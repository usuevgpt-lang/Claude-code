# Проверка перед выдачей

- [ ] Каждая ссылка [n] есть в `sources.md` в списке «Принятые»
- [ ] Ни один отклонённый источник не использован
- [ ] Каждое число, дата, цитата сверены с источником (lead открыл оригинал для ключевых)
- [ ] Утверждения с одним семейством источников помечены `[один источник]`
- [ ] Противоречия либо объяснены, либо вынесены как открытые
- [ ] Технические значения (давления, размеры, эффективности, цены) помечены «требует проверки инженером»
- [ ] Нет конфиденциальных данных в отчёте, который пойдёт наружу
- [ ] Дата актуальности указана для цен, статусов, наличия
