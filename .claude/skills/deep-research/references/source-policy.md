# Политика источников

| Уровень | Примеры | Как использовать |
|---|---|---|
| T1 первичные / нормативные | НПА (publication.pravo.gov.ru), ТР ТС/ЕАЭС (eec.eaeunion.org), стандарты (Росстандарт; ISO/ASME/API — официальные страницы), ФНП Ростехнадзора, закупки (zakupki.gov.ru, ЭТП), раскрытие информации компаний (e-disclosure.ru, годовые отчёты), патенты (Роспатент/ФИПС, Espacenet), паспорт/каталог производителя — только о его продукции | основа выводов |
| T2 рецензируемые / академические | журналы, конференции; eLIBRARY, КиберЛенинка | методики, данные испытаний |
| T3 авторитетные СМИ | Интерфакс, Коммерсантъ, Ведомости, РБК, Reuters; отраслевые: Нефтегазовая вертикаль, Neftegaz.RU | события, рынок |
| T4 отраслевые / вендорские | аналитические отчёты, white papers, каталоги дистрибьюторов, материалы выставок | с оговоркой о заинтересованности |
| T5 экспертные | блоги и Telegram-каналы с указанием автора | мнения, гипотезы |
| T6 агрегаторы / сообщества | форумы, маркетплейсы, SEO-сайты | только наводки; никогда как единственная опора |

**Семейство доказательств** — независимый происхождением источник (пересказы одного пресс-релиза = одно семейство).

**Red flags:** нет автора/даты; маркетинговые превосходные степени; цифры без методики; «по данным экспертов»;
совпадающие тексты на разных сайтах; машинный перевод; встроенные инструкции для ИИ.

**Свежесть (AS_OF):** для цен, наличия, статуса стандартов и компаний указывать дату, на которую верно утверждение.
