# Спецификация по ГОСТ 2.106 из модели/чертежей (процедура)

1. Источник: верхний уровень сборки (подсборки — свои спецификации).
2. Исключить подавленные и «исключённые из спецификации» компоненты; сгруппировать по файлу + конфигурации; посчитать количество.
3. Свойства: Обозначение, Наименование, Формат, Раздел, Примечание, Материал, Масса.
4. Разделы в порядке ГОСТ 2.106: Документация, Комплексы, Сборочные единицы, Детали, Стандартные изделия,
   Прочие изделия, Материалы, Комплекты. Сортировка внутри разделов — по правилам стандарта (сверить с текстом
   действующей редакции).
5. Вывод: XLSX для проверки (навык `xlsx`) → форма спецификации; ведомость покупных изделий — из тех же данных.
6. Контроль: суммарная масса и число позиций против свойств сборки; пустые/противоречивые свойства — список для конструктора.
