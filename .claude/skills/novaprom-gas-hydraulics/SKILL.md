# Газодинамика природного газа (НОВАПРОМ)

## Жёсткие правила
1. **Всегда уточнять базу расхода:** стандартные условия ГОСТ 2939-63 (20 °C; 101,325 кПа) — «ст. м³»;
   нормальные (0 °C) — «нм³» (часто в зарубежных каталогах); ISO 13443 (15 °C) — у некоторых поставщиков.
   Перепутанная база даёт ошибку 5–7 %. Если в ОЛ не указано — спросить.
2. **Абсолютное vs избыточное давление** — ключи `p_abs` / `p_g`. Нельзя считать Z и плотность по избыточному.
3. Коэффициенты, нормативы скорости, ΔP допустимые — только из ОЛ/ОТТ/норматива с источником.
   «Типовые» допустимые скорости — не норматив; если используются, писать «принято по практике, уточнить по ОТТ».
4. Z считается основным методом и сравнивается с остальными; расхождение > 2 % — предупреждение
   и уточнение по ГОСТ 30319.2/30319.3-2015 или по полному составу (CoolProp).
5. Для коммерческого учёта расхода газа скрипт не применять — только ГОСТ 30319.x и ГОСТ 8.586/8.740/8.611 (по типу СИ).
6. Формат результата: ИСХОДНЫЕ ДАННЫЕ → НОРМАТИВ → ФОРМУЛА → ПОДСТАНОВКА → РЕЗУЛЬТАТ → ПРОВЕРКА.

## Методы расчёта Z
| z_method | Основа | Когда |
|---|---|---|
| `gazprom` | СТО Газпром 2-3.5-051-2006 / ОНТП 51-1-85, по ρ_с | по умолчанию, инженерные расчёты |
| `papay` | корреляция Papay + Sutton (псевдокритика по относительной плотности) | независимая проверка |
| `coolprop` | CoolProp HEOS (GERG-2008 для смесей) по полному составу | есть компонентный состав; JT-эффект |
| `value` | значение Z из документа (паспорт газа, расчёт заказчика) | когда Z задан извне |

CoolProp — открытая библиотека (MIT), установка: `pip install CoolProp`. Без неё работают gazprom/papay.

## Порядок работы
1. Исходные: Q (max/min, база), p (абс./изб.) и t на входе, состав газа или ρ_с, μ (вязкость) для ΔP.
2. Свойства в рабочих условиях (`properties`) → скорость/DN → ΔP → (при редуцировании) JT-охлаждение и подогрев.
3. Проверить режимы min/max расхода и min/max давления — худший случай для скорости обычно при min p и max Q.
4. Передать результаты (Q_р, ρ, μ) в навыки фильтрации, теплообмена, трубопроводов — с указанием, откуда взяты.

## Подсказки по данным (не нормативы — требуют подтверждения)
- Вязкость природного газа при 0–30 °C и до ~10 МПа обычно порядка 1,0–1,4·10⁻⁵ Па·с; точнее — CoolProp/справочник.
- Эквивалентная шероховатость стальных труб зависит от состояния (новые/после эксплуатации) — источник указать.
- Средний коэффициент Джоуля–Томсона природного газа зависит от p, T и состава; лучше считать по составу (CoolProp).
