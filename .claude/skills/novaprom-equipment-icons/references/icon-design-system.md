# NOVAPROM ICON DESIGN SYSTEM — спецификация иконок оборудования

**Что это.** Описание стиля иконок сайта novaprom.ru, восстановленное по реальным файлам (reverse-engineered).

**Источник данных.** Иконки скачаны 2026-10-03 из `/assets/templates/img/ico/**`.
- Измерения выполнены программой: lxml + svgelements для геометрии; рендер cairosvg, «чернила» — пиксели с alpha ≥ 0,5.
- Машиночитаемая версия: `icon-spec.json` (рядом). Он включает измерения по каждой иконке (`per_icon`) и агрегаты по семействам (`family_summary_raw`).
- Все числа ниже взяты из этих измерений. Где измерения нет, это сказано прямо.
- Единицы — user units SVG (= px при экспорте 1:1).
- Поля и «живая область» (live area) считаются по габариту, включающему половину толщины линии.

Эталонные файлы семейства tile лежат в `reference-icons/`. Это публичные иконки сайта компании, использовать их только для сравнения.

## 2. Семейство tile (основное)

### 2.1 Холст и размеры показа
- `viewBox="0 0 220 160"` (11:8, аспект 1,375); `width`/`height` равны viewBox (экспорт 1:1).
- **Главная / каталог:** `.tile_img{width:30%}`, это ≈ 105–110 px ширины, масштаб ≈ 0,48.
- **Карточки подкатегорий:** `height:174px; object-fit:contain`, это ≈ 239 px ширины, масштаб ≈ 1,09.
- Поэтому сравнение и проверку читаемости делаем на **106 px и 239 px**.

### 2.2 Цвет и заливка
- Линия: **#4D7C90** (стальной синий). Это 100 % обводок, 579 из 579. Этого цвета нет в CSS сайта; там фирменные #FDB913 / #1C1C1C / #FFFFFF.
- Заливка: **#F5F5F5**, 274 фигуры. Работает **только как «заслонка»** (occluder): закрывает линии, лежащие позади тела, то есть удаляет невидимые линии.
  - Это никогда не видимое цветовое пятно.
  - Отношение залитых фигур к обведённым: медиана 0,5.
- В пикселях: #F5F5F5 ≈ 75–86 %, #4D7C90 ≈ 14–25 % закрашенных пикселей.
- Нет градиентов, прозрачности, теней, трансформаций, CSS-классов и `currentColor`. Цвета «зашиты» в атрибуты.

### 2.3 Толщина линий

|---|---|---|---|
| **2** | Силуэт переднего плана и ключевые элементы (корпус, опоры) | 128 | медиана **26,5 %**, диапазон 17–54,5 % по иконкам |
| **1** | Детали, задний план, линии кривизны, стыки | 448 | остальное |
| 0,75 | Выброс: 3 фигуры только в ico-tile-8 | 3 | — |

- Относительно холста: 1 unit = 0,45 % ширины / 0,625 % высоты; 2 unit = 0,91 % / 1,25 %.
- **На экране:** при 106 px линии 1 и 2 unit дают 0,48 / 0,96 px (волосяные линии); при 239 px — 1,09 / 2,17 px.

### 2.4 Стыки и концы линий
- `stroke-linejoin="round"`: 517 из 579 (89,3 %).
- `stroke-linecap` butt (по умолчанию): 539 из 579 (93,1 %); round: 40.
- `stroke-miterlimit="10"` у всех 579 обводок. Это подпись экспорта из Figma.
- Исключения внутри эталона:
  - ico-tile-10, -11 и -13 в основном с miter-стыками (1, 2 и 9 round соответственно);
  - ico-tile-6 и -9 имеют по 15 round-концов.

### 2.5 Проекция и геометрия
- **Трёхчетвертная перспектива с низкой точкой зрения.** Это не изометрия и не ортогональная проекция.
  - Вертикали строго вертикальны.
  - Уходящие рёбра идут под **±4…12°** к горизонтали.
  - Изометрических осей 30° и диагоналей 45° нет.
- Доли длины прямых отрезков по семейству (взвешено по длине):

  | Направление | Доля |
  |---|---|
  | Вертикали | 51,9 % |
  | Горизонтали | 8,4 % |
  | Уходящие ±4…12° | ≈ 25 % |
  | 30° | < 1 % |
  | 45° | < 1 % |

  Медиана по иконкам: вертикали 61,6 %, горизонтали 10,2 %, прочие наклонные 27,1 %. Максимум по иконкам: 30° — 6,6 %, 45° — 2,2 %.
- Прямые и кривые по длине: медиана 55,5 % / 44,5 %. ico-tile-14 (КТП) — 100 % прямые.
- **Цилиндры** (корпуса, патрубки, фланцы):
  - торцы — эллипсы с отношением малой оси к большой: медиана медиан **0,54**; медианы по иконкам 0,447–0,683; общий разброс 0,21–0,87;
  - фланцы — **стопка эллипсов**;
  - кривизна передаётся **3–8 параллельными линиями**, сгущёнными к одной стороне (на вертикальном цилиндре — к краю, на горизонтальном — к низу). Штриховых заливок нет.
- **Всё нарисовано `<path>`** из отрезков и кубических кривых Безье: нет `<circle>`, `<ellipse>`, `rx`, дуг `A`.
  - Радиусы скруглений по кубикам: медиана медиан 11,6 unit.
  - Минимальный радиус: медиана 6,5 (по иконкам 1,6–14,5).

### 2.7 Компоновка

- Вертикальное центрирование тоже точное (медиана −0,05 %). Исключение — ico-tile-11 (−6,4 %).
- **Фиксированной безопасной зоны нет:** объект масштабируют под холст, высокие касаются верха и низа, широкие — боков.

- Визуальный вес:

## 5. Правила для новых иконок (из `reproduction_rules_for_new_icons`)
1. **Холст.** 220×160 для плиток, 65×50 для меню; экспорт 1:1, `width`/`height` = viewBox.
2. **Перспектива.**
   - Трёхчетвертный вид: вертикали строго вертикальны, уходящие горизонтали под 4–12°.
   - Без изометрии 30° и диагоналей 45°.
3. **Линии.**
   - Только #4D7C90 (светлый UI) или #FDB913 (тёмный UI).
   - Две толщины: 2 unit для силуэта переднего плана и ключевых элементов (≈ 20–30 % длины линий), 1 unit для деталей и заднего плана.
4. **Заливка.**
   - Каждое замкнутое тело заливается #F5F5F5 (светлый) или #1C1C1C (тёмный) только чтобы скрыть линии за ним.
   - Без градиентов, прозрачности и теней.
5. **Стыки и концы.** linejoin round (≈ 90 %), linecap butt (≈ 93 %), miterlimit 10.
6. **Цилиндры.**
   - Торцы — эллипсы с отношением осей 0,45–0,65; фланцы — стопкой эллипсов.
   - Кривизна передаётся 3–8 вертикальными линиями, сгущёнными к одной стороне.
7. **Центр и заполнение.**
   - Горизонтально центр габарита совпадает с центром холста.
   - Объект занимает ≈ 75–80 % ширины и высоты; «чернила» ≈ 35–40 % холста вместе с заливками.
8. **Бюджет деталей.** Плитки: 20–60 paths, 50–200 узлов. Меню: 9–25 paths, 30–80 узлов.

Дополнительно, по эталону:
- Всё делать `<path>`; эллипсы — 4 кубическими сегментами.
- Порядок рисования: от дальнего к ближнему (painter's algorithm), чтобы заслонки работали.

## 6. Известные проблемы (не исправлять на живом сайте без отдельного решения пользователя)
1. **Волосяные линии на главной.** При ≈ 106 px линии 1 unit рисуются толщиной **0,48 px**, линии 2 unit — 0,96 px. Детали почти исчезают; при 239 px всё нормально (1,09 / 2,17 px).
   - Новую иконку обязательно смотреть на 106 px.
   - Варианты решения выбирает пользователь: отдельная версия для малого размера с более толстыми линиями, меньше мелких деталей, другой размер показа.
2. **PNG-плитки не совпадают со стилем.** 9 плиток блочно-модульного оборудования — глянцевые цветные 3D-рендеры:
   - 1536×1024 (одна 1024×1024), **1,65–2,95 МБ каждая, 22,9 МБ всего**, при показе ≈ 100–240 px;
   - стиль ломает линейную систему;
   - это кандидаты на перерисовку в этой системе, каждая — отдельной задачей с согласованием.
3. **Одна иконка — разные изделия:**
   - ico-tile-9: категория фильтров, сепараторы СГ-НП, газовые и жидкостные коалесцеры;
   - ico-tile-10: сепараторы, НГС, ФГГ горизонтальные;
   - ico-tile-5: ФЖ-НП и фильтры-коалесцеры;
   - ico-tile-7: магистральные фильтры и ФГВ вертикальные;
   - ico-tile-8: все 10 страниц СОД Ду300…Ду1400.

   **Новые иконки не должны повторять эту практику:** одно изделие — свой рисунок, с его реальными видимыми элементами.
4. **Внутренние несоответствия эталона:**
   - ico-tile-10/-11/-13 в основном miter-стыки при правиле «round»;
   - 0,75 unit в ico-tile-8;
   - вертикальное смещение ico-tile-11 (−6,4 %);
   - ico-tile-6 выходит за холст на 0,4 unit и держится на clipPath;
   - ico-tile-2 двойной ширины.

   `check_novaprom_style.py` показывает их как WARN — это ожидаемо.
5. **Цвета зашиты в файлы**, а #4D7C90 нет в CSS. Перекрасить иконки через CSS (`currentColor`) нельзя; для тёмного фона нужна отдельная версия (как dropdown).
6. **Семейство simple несогласованно:** два цвета, две толщины, логистика на непрозрачном белом фоне.

## 7. Как `check_novaprom_style.py` использует эту спецификацию
| Проверка | Источник в `icon-spec.json` | Статус при отклонении |
|---|---|---|
| Холст, width/height | `family_summary_raw.<fam>.viewBoxes` | FAIL (неизвестный холст) / WARN (известный выброс) |
| Цвета линий и заливок | `stroke_colour_element_counts`, `fill_colour_element_counts` | FAIL |
| Толщины | `stroke_width_element_counts`: ≥ 5 % фигур — норма, остальные — выбросы | FAIL / WARN |
| Стыки, концы, miterlimit | `linejoin_counts`, `linecap_counts`, `miterlimit_counts` | WARN |
