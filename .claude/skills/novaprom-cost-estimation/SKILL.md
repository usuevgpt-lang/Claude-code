# Себестоимость оборудования (НОВАПРОМ)

## Жёсткие правила
1. Каждая позиция помечается: **calc** (расчётные данные — масса из модели/расчёта, нормативная трудоёмкость),
   **market** (рыночные — КП, прайс, счёт, с датой), **assumed** (допущение — аналог, экспертная оценка).
   Смешивать нельзя: если количество расчётное, а цена рыночная — `kind: calc`, `price_kind: market`.
2. Никаких «средних по рынку» цен без источника и даты. Нет цены — позиция `assumed` с широкой
   неопределённостью и задачей «запросить КП» (навык `novaprom-procurement-research`).
3. Ставки (нормо-час, накладные, рентабельность) — из учётной политики/данных предприятия, которые даёт
   пользователь. Не придумывать. Ставка НДС — проверить актуальную (с 01.01.2026 в РФ — 22 %, подтвердить по НК РФ).
4. Результат всегда содержит диапазон (неопределённость) и список позиций, которые сильнее всего на него влияют.
5. Цены и себестоимость — коммерческая тайна: не отправлять во внешние сервисы, не коммитить в публичный репозиторий.

## Порядок
1. Состав изделия: из спецификации/модели (ведомость материалов — навык `novaprom-cad`; масса — `vessel_calc.py`,
   тип `mass`). Отход/раскрой — по данным производства.
2. Покупные: затворы, фильтроэлементы, регуляторы, КИПиА, арматура, подогреватели — КП/прайсы с датой.
3. Трудоёмкость по переделам: заготовка, вальцовка/гибка, сварка, мехобработка, сборка, НК, испытания, покраска,
   электромонтаж/автоматика, упаковка — нормо-часы по техпроцессу или аналогу (указать аналог).
4. Услуги на стороне: НК, термообработка, покраска, испытания, сертификация/декларирование, доставка.
5. JSON по `references/example-input.json` →
   ```bash
   python ${CLAUDE_SKILL_DIR}/scripts/cost_calc.py input.json --out estimate.md --xlsx estimate.xlsx
   ```
   Excel содержит формулы (пересчитывается при изменении цен) — для правки и оформления использовать навык `xlsx`.
6. Сравнение вариантов: два JSON → два расчёта → таблица разниц по статьям с объяснением.
7. Для ТКП — навык `novaprom-commercial-proposal`; цифры перед выдачей заказчику — `novaprom-engineering-review`.
