# Реестр справочных значений «на сверку»

Значения ниже записаны по памяти инженерной практики и **не сверены с текстом стандарта в этой среде**.
Правило: пока в колонке «Сверено» нет даты и ФИО, значение используется только для оценки, а в отчёте
ставится пометка «справочно, не сверено». После сверки пользователь (или агент по его поручению с
открытым текстом стандарта) заполняет колонку — тогда значение можно давать со ссылкой на пункт.
