# Методика: формулы, обозначения, область применения

Источник формул — ГОСТ 34233.1/.2/.3-2017 (введены взамен ГОСТ Р 52857.1/.2/.3-2007, ГОСТ 14249-89).
Перед выпуском расчёта сверить номер пункта/формулы с имеющейся у пользователя редакцией стандарта
и записать его в отчёт. Скрипт ссылается на стандарт без номеров формул, чтобы не выдумать нумерацию.

## Обозначения
| Символ | Смысл | Ед. |
|---|---|---|
| p | расчётное внутреннее (наружное) избыточное давление | МПа |
| D | внутренний диаметр | мм |
| s, s1 | исполнительная толщина стенки обечайки, днища | мм |
| c = c1 + c2 + c3 | прибавки: коррозия/эрозия; минусовой допуск; технологическая (утонение при штамповке и т.п.) | мм |
| [σ] | допускаемое напряжение при расчётной температуре | МПа |
| φ, φp | коэффициент прочности сварного шва (продольного для обечаек) | — |
| E | модуль продольной упругости при расчётной температуре | МПа |
| n_y | коэффициент запаса устойчивости | — |

## Цилиндрическая обечайка, внутреннее давление
- s_p = p·D / (2[σ]φp − p); s ≥ s_p + c
- [p] = 2[σ]φp(s − c) / (D + (s − c))
- Применимость: (s − c)/D ≤ 0,1 при D ≥ 200 мм; ≤ 0,3 при D < 200 мм.

## Цилиндрическая обечайка, наружное давление (гладкая, без колец)
- [p] = [p]_П / √(1 + ([p]_П/[p]_E)²)
- [p]_П = 2[σ](s − c)/(D + (s − c))
- [p]_E = 2,08·10⁻⁵·E/(n_y·B1)·(D/l)·[100(s − c)/D]^2,5
- B1 = min{1; 9,45·(D/l)·√(D/(100(s − c)))}
- l — расчётная длина (с учётом части выпуклых днищ) — определить по стандарту.
- n_y — по ГОСТ 34233.1 для рабочих условий и условий испытаний (взять из стандарта, не по памяти).

## Гладкая коническая обечайка (α1 ≤ 70°)
- s_к.p = p·D_к/(2φp[σ] − p) · 1/cos α1
- [p] = 2[σ]φp(s_к − c)/(D_к/cos α1 + (s_к − c))
- Зоны сопряжения с цилиндром (с тороидальным переходом и без) — отдельный расчёт, скриптом не выполняется.

## Эллиптическое и полусферическое днище
- R = D²/(4H) (для H = 0,25D: R = D; для H = 0,5D: R = 0,5D)
- s_1p = p·R/(2φ[σ] − 0,5p); s1 ≥ s_1p + c
- [p] = 2(s1 − c)φ[σ]/(R + 0,5(s1 − c))
- Применимость: 0,002 ≤ (s1 − c)/D ≤ 0,1; 0,2 ≤ H/D ≤ 0,5.

## Плоское круглое днище/крышка
- s_1p = K·K0·D_p·√(p/(φ[σ])); [p] = ((s1 − c)/(K·K0·D_p))²·φ[σ]
- K и D_p — по типу соединения с обечайкой (таблица/рисунки ГОСТ 34233.2). Не подставлять K «по памяти».
- K0 — коэффициент ослабления отверстиями; при отсутствии отверстий K0 = 1.
- Проверить ограничение по (s1 − c)/D_p и поправку при его превышении — по тексту стандарта.

## Укрепление отверстий (одиночное отверстие, радиальный штуцер)
- D_p: цилиндр — D; эллиптическое днище — 2D²/(4H)·√(1 − 4(D² − 4H²)x²/D⁴); полусфера — D; конус — D_к/cos α.
- s_p — расчётная толщина элемента без отверстия (цилиндр/конус: pD_p/(2φ[σ] − p); выпуклое днище: pD_p/(4φ[σ] − p)).
- d_p = d + 2c_s.
- d_0 = 2((s − c)/s_p − 0,8)·√(D_p(s − c)) — если d_p ≤ d_0, укрепление не требуется.
- Условие укрепления: l_1p(s1 − s_1p − c_s)χ1 + l_2p·s2·χ2 + l_3p(s3 − c_s − c_s1)χ3 + l_p(s − s_p − c) ≥ 0,5(d_p − d_0p)s_p,
  где d_0p = 0,4√(D_p(s − c)), l_p = min{l; √(D_p(s − c))}, l_1p = min{l1; 1,25√((d + 2c_s)(s1 − c_s))},
  l_2p = min{l2; √(D_p(s2 + s − c))}, l_3p = min{l3; 0,5√((d + 2c_s)(s3 − c_s − c_s1))}, χi = min{1; [σ]i/[σ]}.
- Не выполняется скриптом: [p] ослабленного элемента (коэффициент V), наклонные/смещённые штуцеры,
  взаимовлияние отверстий, внешние нагрузки на штуцер (раздел 34233.3 о нагрузках на штуцер).

## Пробное давление и условия испытаний
- P_пр = k·p·[σ]20/[σ]t; k и особые случаи (литые сосуды, минимальные значения, многокамерные аппараты) —
  по ФНП ОРПД (приказ Ростехнадзора № 536 от 15.12.2020), ТР ТС 032/2013, ГОСТ 34347-2017 и ОТТ заказчика.
- [σ]_и = η·R_e20/n_т (n_т для условий испытаний — по ГОСТ 34233.1).
- Проверка: P_пр + p_гидростат ≤ [p]_и.

## Допускаемые напряжения по механическим характеристикам (ГОСТ 34233.1)
- [σ] = η·min{R_e/t/n_т; R_m/20/n_в; R_д/n_д; R_1%/n_п}; коэффициенты запаса — из ГОСТ 34233.1.
- Предпочтительно брать [σ] прямо из таблиц приложения ГОСТ 34233.1 для марки, толщины и температуры.
