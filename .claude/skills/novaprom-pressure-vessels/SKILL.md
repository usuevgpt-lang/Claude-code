# Сосуды и аппараты под давлением (НОВАПРОМ)

Навык для предварительных и поверочных расчётов элементов сосудов. Результат — прослеживаемый
отчёт, в котором у каждого числа есть источник.

## Жёсткие правила

1. **Никаких выдуманных коэффициентов.** [σ], φ, E, K, n_y, k пробного давления, прибавки — только
   из нормативного документа, ОЛ/ТЗ заказчика или сертификата, с указанием источника в JSON
   (`{"value": 177, "source": "ГОСТ 34233.1-2017, табл. А.1, 09Г2С, 100 °C"}`).
   Если значения нет — спросить пользователя или явно пометить «ТРЕБУЕТ УТОЧНЕНИЯ», не подставлять «типичное».
2. Справочные значения из `references/coefficients-register.md` имеют статус «не сверено» — их можно
   использовать только для оценки, с пометкой в отчёте, пока пользователь не подтвердит сверку с текстом стандарта.
3. Формат каждого расчёта: **ИСХОДНЫЕ ДАННЫЕ → НОРМАТИВ → ФОРМУЛА → ПОДСТАНОВКА → РЕЗУЛЬТАТ → ПРОВЕРКА.**
   Скрипт выдаёт именно этот формат — не переписывай результат «своими словами» без формул.
4. Давление в расчёте — расчётное (избыточное), МПа; размеры — мм; напряжения — МПа.
5. Скрипт — помощник, не сертифицированное ПО. Отчёт для заказчика/экспертизы: независимая проверка
   (субагент `engineering-reviewer`) + подпись ответственного инженера; при необходимости — ПАССАТ/аналог.
6. Не изменять производственные документы (КД, расчёты в архиве) без явного разрешения — работать с копиями.

## Порядок работы

1. Собрать исходные данные: среда, p и t расчётные, p и t пробные, минимальная температура стенки,
   D, длины, материал, способ изготовления днищ, тип и объём контроля швов, срок службы и скорость коррозии.
   Недостающее — список вопросов пользователю (одним сообщением).
2. Определить применимые документы (`references/normative-map.md`): ТР ТС 032/2013, ФНП ОРПД,
   ГОСТ 34347-2017, ГОСТ 34233.x-2017, ОТТ/ТЗ заказчика (ОТТ Транснефти — навык `novaprom-transneft`).
3. Выбрать материал (навык `novaprom-materials`), определить [σ] при 20 °C и при t, φ, прибавки c1, c2, c3.
4. Подготовить JSON (пример: `references/example-input.json`) и запустить:
   ```bash
   python ${CLAUDE_SKILL_DIR}/scripts/vessel_calc.py input.json --out report.md
   ```
   Код возврата 3 = есть невыполненные проверки (это результат, а не ошибка); 1 или 2 — ошибка входных данных.
5. Проанализировать предупреждения: каждый «ИСТОЧНИК НЕ УКАЗАН» либо закрыть, либо вынести в
   раздел «Допущения» итогового отчёта.
6. Для ответственных расчётов — независимая проверка по навыку `novaprom-engineering-review`.
7. Итог пользователю: таблица «элемент — s_треб — s_прин — [p] — p — вывод», затем полный отчёт.

## Что считает скрипт (`scripts/vessel_calc.py`)

| type | Элемент | Норматив |
|---|---|---|
| `cyl_internal` | цилиндрическая обечайка, внутреннее давление | ГОСТ 34233.2 |
| `cyl_external` | обечайка, наружное давление (без колец жёсткости) | ГОСТ 34233.2 |
| `cone_internal` | гладкая коническая обечайка (без зон сопряжения) | ГОСТ 34233.2 |
| `ellipsoidal_head` | эллиптическое (H=0,25D) и полусферическое (H=0,5D) днище | ГОСТ 34233.2 |
| `flat_head` | плоское круглое днище/крышка (K по типу закрепления — вход) | ГОСТ 34233.2 |
| `opening` | одиночное отверстие с радиальным штуцером: d0 и условие укрепления площадей | ГОСТ 34233.3 |
| `test_pressure` | пробное давление и проверка обечайки при испытании | ФНП ОРПД, ТР ТС 032, ГОСТ 34347, ГОСТ 34233.1 |
| `allowable_stress` | [σ] по механическим характеристикам | ГОСТ 34233.1 |
| `mass` | масса обечаек, эллиптических днищ, плоских деталей | геометрия |

**Не считает** (выполнять по полному тексту стандарта/ПО и явно сообщать пользователю):
фланцевые соединения (ГОСТ 34233.4), опорные нагрузки (34233.5), малоцикловая усталость (34233.6),
трубные решётки (34233.7), рубашки (34233.8), колонные аппараты (34233.9), сероводородные среды (34233.10),
смещение кромок/некруглость (34233.11), зоны сопряжения конус–цилиндр, торосферические днища,
допускаемое давление ослабленного элемента с коэффициентом V, взаимное влияние отверстий, нагрузки на штуцеры.

Описание формул, обозначений и областей применимости — `references/gost-34233-method.md`.

## Контроль результата перед выдачей

- (s − c)/D в области применимости; H/D днища 0,2…0,5.
- Минусовой допуск листа учтён в c2, утонение при штамповке днища — в c3 (по данным изготовителя днищ).
- Пробное давление проверено на прочность при испытании (с гидростатикой при вертикальном испытании).
- Для штуцеров проверена и собственная толщина стенки (s1 ≥ s1p + cs).
- Все предупреждения скрипта либо закрыты, либо перечислены в допущениях.
- Сравнение с аналогом/прототипом: если результат отличается от аналогичного изделия НОВАПРОМ > 15 %, найти причину.
