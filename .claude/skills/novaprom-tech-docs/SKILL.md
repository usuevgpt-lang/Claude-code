# Техническая документация (НОВАПРОМ)

## Правила
1. Структура документа — по действующему стандарту (статус проверить через `novaprom-normative-check`):
   ТУ — ГОСТ 2.114-2016; ЭД (паспорт, РЭ, формуляр) — ГОСТ 2.601-2019, ГОСТ 2.610-2019; текстовые документы —
   ГОСТ 2.105-2019; для оборудования под давлением — требования ТР ТС 032/2013 к паспорту и РЭ, форма паспорта
   сосуда — по ГОСТ 34347-2017 (приложение) / требованиям заказчика.
2. Требования заказчика (ОТТ, ТЗ) имеют приоритет по составу и содержанию — сверять матрицей (`novaprom-transneft`).
3. Технические данные в документах = расчёт/КД. Не дописывать «типовые» значения (давления, ресурс, сроки службы,
   методики испытаний) без источника — ставить «[ТРЕБУЕТ УТОЧНЕНИЯ: …]».
4. Исходные документы не перезаписывать — создавать новую версию/копию; правки существующих — режим
   рецензирования (tracked changes) через навык `docx`.
5. ПМИ: для каждого вида испытаний — цель, объём, условия, средства измерений (с точностью), методика,
   критерии приёмки, оформление результатов. Испытательное давление и время выдержки — из нормативов/ОТТ
   с указанием пункта.

## Шаблоны структур — `references/doc-structures.md`
ТУ · ПМИ (приёмо-сдаточные, периодические, типовые; приёмочные для опытного образца) · паспорт ·
РЭ · обоснование безопасности · технический отчёт · опросный лист.

## Инструменты
DOCX — навык `docx`; XLSX (таблицы, ведомости) — `xlsx`; PDF/OCR сканов — `pdf`; проверка нормативных
ссылок — `novaprom-normative-check`. Финальный документ — визуальная проверка PDF-рендера (таблицы, переносы, шрифты).
