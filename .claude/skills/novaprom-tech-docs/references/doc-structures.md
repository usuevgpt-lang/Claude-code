# Типовые структуры документов (сверять с действующей редакцией стандартов)

## Технические условия (ГОСТ 2.114-2016)
Вводная часть (наименование, назначение, область применения, пример записи при заказе) · Технические требования
(основные параметры и характеристики, требования к сырью/материалам/покупным изделиям, комплектность,
маркировка, упаковка) · Требования безопасности · Требования охраны окружающей среды · Правила приёмки ·
Методы контроля · Транспортирование и хранение · Указания по эксплуатации · Гарантии изготовителя ·
Приложение: перечень ссылочных документов.

## Программа и методика испытаний
Объект испытаний · Цель · Общие положения (место, организация, документы) · Объём испытаний (таблица видов
испытаний и проверок) · Условия и порядок проведения · Материально-техническое обеспечение · Метрологическое
обеспечение (СИ, класс точности, поверка) · Методики (для каждой проверки: что, как, критерий приёмки) ·
Отчётность (протоколы, акт) · Требования безопасности при испытаниях.

## Паспорт (ГОСТ 2.610-2019 / требования ТР ТС 032/2013 к паспорту оборудования под давлением)
Основные сведения об изделии · Основные технические данные · Комплектность · Ресурсы, сроки службы и хранения,
гарантии изготовителя · Консервация · Свидетельство об упаковывании · Свидетельство о приёмке · Движение изделия
при эксплуатации · Сведения об утилизации · Для сосудов: данные о материалах, сварке, НК, испытаниях,
расчётные параметры, чертёж общего вида (по форме стандарта/заказчика).

## Руководство по эксплуатации (ГОСТ 2.610-2019)
Описание и работа (назначение, характеристики, состав, устройство и работа, средства измерения, маркировка,
упаковка) · Использование по назначению (ограничения, подготовка, порядок работы, действия в экстремальных
условиях) · Техническое обслуживание · Текущий ремонт · Хранение · Транспортирование · Утилизация.
Для быстросъёмных затворов — отдельно порядок открытия/закрытия и проверка блокировок.

## Технический отчёт
Цель и исходные данные (с источниками) · Методика · Результаты · Анализ и сравнение с требованиями · Выводы ·
Допущения и ограничения · Приложения (расчёты, протоколы).
