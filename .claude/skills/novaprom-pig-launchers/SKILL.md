# Камеры пуска и приёма СОД (НОВАПРОМ)

По данным сайта НОВАПРОМ: камеры КПР-НП DN 100–1600, PN до 25 МПа, изготовление по ГОСТ 34568-2019
(наименование и требования стандарта сверять по тексту). Для объектов Транснефти — дополнительно ОТТ
(навык `novaprom-transneft`).

## Правила
1. Геометрия (длины расширенной части, кратность к длине снаряда, диаметры) — по стандарту/ОТТ и паспорту
   конкретного СОД/внутритрубного инспектирующего прибора заказчика. «Правила большого пальца» из
   зарубежных руководств — только как ориентир с пометкой.
2. Прочность: определить, по какому документу считать корпус (как сосуд — ГОСТ 34233; как элемент трубопровода —
   СП 36.13330/ОТТ; требования ГОСТ 34568) — решение фиксировать в отчёте. Расчёты — `novaprom-pressure-vessels`,
   `novaprom-piping`. Концевой затвор — `novaprom-valves-closures`.
3. Безопасность: блокировка открытия затвора под давлением, контроль отсутствия давления (манометр/кран
   сброса), воздушник в верхней точке, дренаж в нижней — проверять в каждом проекте.

## Конструктивный чек-лист (`references/design-checklist.md`)
Корпус (расширенная часть) · концентрический/эксцентрический переход · горловина/патрубок основной трубы ·
концевой затвор · патрубок запасовки (кикер) · байпас/продувка · дренаж · воздушник · манометр/датчик давления ·
сигнализатор прохождения СОД · лоток/тележка/механизм запасовки · опоры (неподвижная/скользящие) · строповочные
устройства · ЗИП · маркировка · антикоррозионное покрытие · климатическое исполнение.

## Расчёты, которые обычно нужны
- толщины стенок корпуса, перехода, патрубков; укрепление отверстий (патрубки на корпусе);
- осевое усилие на затвор и проверка его элементов;
- пробное давление, проверка при испытаниях;
- опоры (вес с водой при испытаниях, с СОД), устойчивость; массы для транспортировки;
- гидравлика продувки/запасовки (скорости, расход) — `novaprom-gas-hydraulics` или `novaprom-piping`.
