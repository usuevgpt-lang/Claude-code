# Трубопроводы (НОВАПРОМ)

## Правила
1. Сначала определить, **какой норматив применим** (это решение, а не формальность):
   - технологические трубопроводы обвязки на площадке — ГОСТ 32388-2013 (+ ОТТ заказчика);
   - магистральные трубопроводы и их узлы (в т.ч. КПП СОД, если заказчик так требует) — СП 36.13330.2012 / ОТТ;
   - газораспределение (ПГБ/ГРП) — СП 62.13330 и связанные ГОСТ;
   - зарубежное ТЗ — ASME B31.3 / B31.8.
   Если неясно — спросить пользователя и указать альтернативы.
2. Все коэффициенты (φ_w, [σ], m, k1, k_н, n, E, W, Y) — из документа с источником. Не подставлять по памяти.
3. Газовые расходы и ΔP газа — навык `novaprom-gas-hydraulics`.
4. Формат: ИСХОДНЫЕ ДАННЫЕ → НОРМАТИВ → ФОРМУЛА → ПОДСТАНОВКА → РЕЗУЛЬТАТ → ПРОВЕРКА.

## Расчёты (`scripts/pipe_calc.py`)
| type | Что |
|---|---|
| `wall_gost32388` | t_R = P·D/(2φ_w[σ] + P), [P] — наружный диаметр |
| `wall_sp36` | δ = n·p·D_н/(2(R1 + n·p)), R1 = R1н·m/(k1·k_н) |
| `wall_b31_3` | t = PD/(2(SEW + PY)) + c, проверка t < D/6 |
| `bend_b31_3` | коэффициенты I для интрадоса/экстрадоса отвода |
| `liquid_dp` | скорость, Re, λ (Колбрук), ΔP жидкости |

```bash
python ${CLAUDE_SKILL_DIR}/scripts/pipe_calc.py input.json --out report.md
```

## Подбор комплектующих — чек-лист
- DN/PN по проекту; рабочее давление при температуре — с учётом снижения допускаемого давления арматуры/фланцев
  с ростом температуры (таблицы стандарта на изделие).
- Материал: по минимальной температуре (в т.ч. для наружной установки — по климату района), среде (H2S → требования
  ГОСТ 34233.10 / ISO 15156 и ОТТ), ударной вязкости — навык `novaprom-materials`.
- Фланцы: ГОСТ 33259-2015 (тип, исполнение уплотнительной поверхности, ряд); прокладки — по среде и давлению.
- Отводы/переходы/тройники/заглушки: стандарт на изделие (ГОСТ 17375/17378/17376/17379 или ГОСТ 30753 и т.п. —
  проверить применимость и статус), ТУ поставщика, требования заказчика (Транснефть/Газпром — только из реестров/
  перечней допущенной продукции, если это требование ОТТ).
- Арматура: тип, класс герметичности, привод, исполнение по климату, наличие сертификатов/деклараций ТР ТС 010/032.
- Для закупки — навык `novaprom-procurement-research`.
