# Чек-лист проверки слайда

| Проверка | Критерий |
|---|---|
| Наложения | ни один текстовый блок не пересекает изображение/фигуру/другой текст |
| Поля | все объекты внутри полей ≥ 0,5″ |
| Переполнение | текст не обрезан, нет автоуменьшения ниже 14 pt |
| Иерархия | один заголовок; ключевая мысль читается за 3 секунды |
| Цвета | только палитра; акцент #FDB913 не более чем на 1–2 элементах |
| Контраст | текст на фото — только на подложке |
| Изображения | пропорции сохранены, нет пикселизации, нет водяных знаков |
| Схемы | одинаковые толщины линий, направления потоков, подписи позиций |
| Таблицы | единицы, выравнивание, нет пустых ячеек без «—» |
| Факты | цифры совпадают с паспортом/расчётом/КП; ссылки на нормативы актуальны |
| Конфиденциальность | нет внутренних цен, имён заказчиков без разрешения, внутренних пометок |
