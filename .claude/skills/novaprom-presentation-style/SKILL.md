# Презентации НОВАПРОМ

Инструмент создания файла — навык `pptx` (Anthropic, редактируемый PowerPoint). Этот навык задаёт стиль,
структуру и контроль качества. Внешние генераторы (Gamma, Canva, SlidesGPT) — только по явному запросу и
только для неконфиденциальных материалов: содержимое уходит в сторонний сервис.

## Стиль (по сайту novaprom.ru, проверить с маркетингом)
- Цвета: янтарный **#FDB913** — акцент (линии, маркеры, номера, выделение 1–2 цифр); почти чёрный **#1C1C1C** —
  заголовки, тёмные фоны; белый — основной фон; стальной синий **#4D7C90** — линии схем и пиктограмм оборудования;
  светло-серый #F5F5F5 — подложки таблиц.
- Шрифт: Raleway (если не установлен у получателя — Arial; для критичных файлов экспортировать PDF).
- Иконки оборудования — по `novaprom-equipment-icons`; логотип — только официальный файл.
- Тон: инженерный, фактический; никаких «лучший/№1» без доказательств.

## Сетка и правила вёрстки
- 16:9; поля ≥ 0,5″ (≈1,27 см); заголовок в одной позиции на всех слайдах; не более 1 идеи на слайд.
- Текст ≥ 14 pt (таблицы ≥ 12 pt); не более ~6 строк основного текста.
- Никаких наложений: текст не заходит на изображения/фигуры, подписи не перекрывают схему; отступы между блоками ≥ 0,2″.
- Фото — реальные (производство, изделия, объекты), без искажения пропорций, с кадрированием; разрешение достаточное
  для проектора; фото объектов заказчика — только с разрешения.
- Схемы — векторно (фигуры PowerPoint или SVG/EMF), единые толщины линий, стрелки потока, подписи позиций.
- Таблицы характеристик: единицы в заголовке столбца, выравнивание чисел по правому краю, DN/PN по ГОСТ.

## Типовая структура технической презентации
Титул → проблема/задача заказчика → решение (изделие/линейка) → принцип работы (схема) → конструкция
(3D/фото с выносками) → характеристики (таблица) → исполнения и опции → соответствие нормативам и документы →
производство и контроль качества → референс-лист → сроки/сервис → контакты.

## Контроль качества (обязательно)
1. Отрендерить каждый слайд в изображение (скрипты навыка `pptx`) и **просмотреть каждый слайд**.
2. Чек-лист на слайд: наложения/выход за поля; обрезанный текст; размер шрифта; контраст; выравнивание по сетке;
   единый стиль заголовков; корректность цифр (сверка с паспортом/расчётом); опечатки.
3. Исправить и перепроверить изменённые слайды. В ответе пользователю — список проверенных слайдов и что исправлено.
Подробный чек-лист — `references/slide-qa.md`.
