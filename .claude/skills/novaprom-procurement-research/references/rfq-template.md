# Шаблон запроса коммерческого предложения поставщику (черновик для пользователя)

Тема: Запрос КП — <позиция>, <кол-во>

Просим направить коммерческое предложение на поставку:
| № | Наименование / тип | Обозначение (модель, ТУ/ГОСТ) | Основные параметры (DN, PN, среда, t) | Кол-во | Ед. |
|---|---|---|---|---|---|

Просим указать: цену за единицу без НДС и с НДС; срок изготовления/поставки; условия поставки (место);
условия оплаты; гарантийный срок; комплект документации (паспорт, РЭ, декларация/сертификат ЕАЭС,
сертификаты на материалы); страну происхождения; срок действия предложения.
Технические требования/опросный лист — во вложении.

(Отправляет пользователь. Не включать сведения о конечном заказчике без необходимости.)
