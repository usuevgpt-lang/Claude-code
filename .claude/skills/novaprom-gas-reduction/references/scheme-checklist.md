# Чек-лист технологической схемы ПГБ/ГРП/БПТГ

- [ ] Входное отключающее устройство (вне и/или внутри блока — по нормативу), изолирующее соединение при необходимости
- [ ] Фильтрация: тип, тонкость, перепадомер, резервирование фильтра или байпас фильтра
- [ ] Узел учёта газа: тип СИ, прямые участки, корректор, требования поставщика газа
- [ ] Подогрев газа: источник тепла, схема (прямой/с промежуточным теплоносителем), регулирование температуры
- [ ] Линии редуцирования: количество (рабочая + резервная), схема защиты (ПЗК + регулятор / монитор + регулятор)
- [ ] ПЗК: верхняя и нижняя уставки, ручной взвод, сигнализация положения
- [ ] ПСК: уставка, пропускная способность, сбросная свеча
- [ ] Одоризация (если требуется): тип одоризатора, ёмкость одоранта
- [ ] Отключающие устройства на выходе, байпас (условия допустимости)
- [ ] Продувочные трубопроводы и свечи, дренажи конденсата
- [ ] КИПиА: манометры, термометры, датчики, ПЛК/телемеханика, сигнализаторы загазованности
- [ ] Блок-бокс: отопление, вентиляция, освещение (взрывозащита), молниезащита, заземление, ОПС
- [ ] Климатическое исполнение, транспортные габариты, монтажная масса
- [ ] Документация: паспорт, РЭ, сертификаты/декларации ТР ТС, ПМИ, расчёты
