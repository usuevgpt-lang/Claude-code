# Проверка сторонних инструментов (НОВАПРОМ)

Ничего не устанавливать и не включать, пока проверка не завершена и пользователь не подтвердил установку.
Статический анализ — без запуска кода. Клонировать только в отдельную папку для анализа.

## 12 шагов
1. **Первоисточник:** оригинальный репозиторий/издатель, а не форк, зеркало или «подборка». Сверить имя пакета
   (тайпсквоттинг: `OCP` vs `cadquery-ocp`).
2. **Репозиторий:** звёзды/форки/issues в контексте (накрученные звёзды при 0 форков и автокоммитах — red flag).
3. **Автор:** кто это, другие проекты, организация.
4. **Лицензия:** файл LICENSE есть; совместимость с коммерческим использованием (NC, Commons Clause — нельзя).
5. **Активность:** дата последнего коммита, частота, реакция на issues безопасности.
6. **Исходный код:** прочитать всё, что будет исполняться (скрипты, хуки, MCP-сервер, `bin/`).
7. **Зависимости:** список, закреплённые версии, известные уязвимости, лишние тяжёлые зависимости.
8. **Install-скрипты:** `postinstall`, `setup.py`, `install.sh/ps1`; **`curl | bash`, `irm | iex`** — отказ.
9. **Сеть:** все URL/домены в коде; телеметрия (по умолчанию вкл./выкл., как отключить); автообновления.
10. **Права:** что получает (shell, файлы, браузер, CAD, учётные данные); хуки (события, команды);
    `allowed-tools` в навыке; локальные серверы и порты (привязка к localhost, аутентификация).
11. **Вредоносность/подозрительное:** обфускация, `eval`/`exec` загруженного кода, скачивание бинарников,
    запись в чужие конфиги (`~/.claude/CLAUDE.md`, настройки других AI-инструментов), `rm -rf`, отправка данных.
12. **Дублирование:** не повторяет ли уже установленное (см. реестр в `docs/ARCHITECTURE.md`).

## Решение
| Вердикт | Когда |
|---|---|
| УСТАНОВИТЬ | всё чисто, нужен, не дублирует |
| ВЕНДОРИТЬ С ИЗМЕНЕНИЯМИ | полезен, но нужны правки (убрать сеть/телеметрию/лишнее); копия с NOTICE, закреплённый коммит |
| НАПИСАТЬ СВОЙ | это по сути набор инструкций, проще и безопаснее сделать локально |
| ОТКЛОНИТЬ | риски не устранимы, лицензия не подходит, дублирует |

Формат отчёта — `references/vetting-report.md`. Инструменты, управляющие SolidWorks/браузером/CRM/сайтом, —
только с отдельного явного разрешения пользователя даже после положительной проверки.
