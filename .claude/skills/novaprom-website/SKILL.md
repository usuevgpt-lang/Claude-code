# Сайт НОВАПРОМ (novaprom.ru)

Факты собраны с публичного сайта 2026-10-03 (только чтение) — при работе с исходниками сверять.

## Технологии
- CMS **MODX Revolution** (заголовок X-Powered-By, пути в robots.txt, дополнение AjaxForm); nginx + PHP.
- Фронтенд: Bootstrap 4.5.3, Font Awesome 4.7, slick, lightGallery; аналитика — Яндекс.Метрика.
- Статика темы: `/assets/templates/…`; иконки оборудования: `/assets/templates/img/ico/…` (SVG, 220×160).
- Карты сайта: две (≈82 и ≈15 URL); schema.org: Organization, WebSite, BreadcrumbList, минимальный Product.
- Бренд: #FDB913, #1C1C1C, белый; иконки #4D7C90 / #F5F5F5; шрифт Raleway 400/700 (в inline-стилях встречается 600 — не подключён).

## Каталог (7 разделов)
Блочно-модульное оборудование · Камеры СОД КПР-НП · Концевые затворы ЗК-НП · Фильтры · Сепараторы ·
Резервуары и ёмкости · КТП.

## Замечания, найденные при осмотре (кандидаты в бэклог; подтвердить)
- PNG-плитки блочно-модульного оборудования 1,6–2,9 МБ каждая (≈23 МБ всего) — конвертировать в WebP/AVIF, ресайз.
- Одна иконка используется для разных продуктов (фильтры / газовые сепараторы / коалесцеры).
- H1 главной — только название бренда; FAQ-блоки без разметки FAQPage; хлебные крошки в schema пропускают категорию.
- Противоречие часов работы (шапка 9–18 vs контакты 08–17 саратовского времени).
- OG-изображение 250×120 и объявлено как PNG, фактически JPEG; favicon 144 px и /favicon.ico — 404.
- Пустой `<img>` на главной; реквизиты (ИНН/ОГРН) на сайте не указаны.

## Порядок любых изменений (обязательный)
1. **Только чтение по умолчанию.** Любое изменение живого сайта, БД, файлов на сервере, настроек MODX —
   только после явного подтверждения пользователя в этой сессии.
2. Резервная копия изменяемых элементов (экспорт шаблона/чанка/ресурса, копия файлов) с датой.
3. Изменения — на тестовой копии/локально; показать diff пользователю.
4. После переноса — очистка кэша MODX и **обязательный QA** (навык `novaprom-website-qa`, субагент `website-qa`).
5. Записать, что изменено и как откатить.
