# Фильтрация и сепарация (НОВАПРОМ)

Продуктовая линейка (сайт novaprom.ru): фильтры газовые ФГ-НП, грязеуловители горизонтальные/вертикальные
ФГГ/ФГВ, коалесцеры, фильтры жидкости ФЖ-НП и самоочищающиеся ФЖ-НП-А, фильтры тонкой очистки,
магистральные фильтры, сепараторы газовые СГ-НП, нефтегазовые НГС.

## Правила
1. Рабочие параметры газа (Q_р, ρ_г, μ) — из `novaprom-gas-hydraulics` для **худшего режима**
   (обычно минимальное давление + максимальный расход). Указать, какой режим считается.
2. K Саудерса–Брауна, пропускная способность и ΔP элементов, допустимый ρw² входного устройства — по данным
   производителя внутренних устройств/элементов или ОТТ заказчика. Литературные значения (GPSA, API 12J)
   допустимы только как «предварительно» с явной пометкой.
3. Эффективность очистки (размер частиц, %, остаточное содержание жидкости) — это требование ОЛ/ОТТ;
   подтверждается данными производителя элементов и ПМИ, не расчётом «из головы».
4. Корпус фильтра — сосуд под давлением: прочность по `novaprom-pressure-vessels`, быстросъёмная крышка — `novaprom-valves-closures`.
5. Формат: ИСХОДНЫЕ ДАННЫЕ → НОРМАТИВ/ИСТОЧНИК → ФОРМУЛА → ПОДСТАНОВКА → РЕЗУЛЬТАТ → ПРОВЕРКА.

## Расчёты (`scripts/filter_calc.py`)
| type | Что |
|---|---|
| `souders_brown` | V_max = k·K·√((ρ_ж − ρ_г)/ρ_г), площадь и D_min сепарационной секции, проверка принятого D |
| `elements_count` | число элементов по расходу на элемент или по скорости фильтрации, с запасом |
| `element_dp` | пересчёт ΔP элемента с каталожных условий на рабочие (квадратичный/линейный закон) |
| `nozzle_check` | скорость и ρw² в патрубках |
| `cyclone_lapple` | d50 и фракционная эффективность циклона (грубая оценка) |

## Порядок подбора фильтра-сепаратора
1. ОЛ: среда, состав, Q min/max (база м³!), p, t, загрязнения (тв. частицы, жидкость: г/м³, размер), требуемая
   степень очистки, допустимый ΔP чистого/загрязнённого, климат, место установки, требования к замене элементов.
2. Свойства газа → Q_р.
3. Ступень 1 (фильтрация/коалесценция): число и типоразмер элементов, компоновка на решётке, ΔP.
4. Ступень 2 (сепарация): тип каплеуловителя, K, D_min; сравнить с D по ступени 1, принять больший.
5. Патрубки: скорость, ρw²; дренажи и сборник жидкости (объём между уровнями сигнализации).
6. Корпус: толщины, крышка-затвор, опоры, масса → `novaprom-pressure-vessels`, `novaprom-cost-estimation`.
7. Итог: таблица режимов (min/max), выбранные элементы с источником данных, открытые вопросы к производителю элементов.

Шаблон опросного листа — `references/questionnaire-filter.md`.
