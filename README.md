# Claude-code
Клод на айфоне 

## Плагины

- **claude-mem** — постоянная память для Claude Code (сжатие контекста между сессиями). Подключается автоматически через `.claude/settings.json`; при первом запуске Claude Code в этом репозитории предложит установить плагин из маркетплейса `thedotmack/claude-mem`.
